# LockFit account and data deletion

The current LockFit account is local to one Android device and has no server copy.

## In the application

1. Open Menu.
2. Open Account.
3. Select “Delete account and all data”.
4. Confirm the irreversible deletion.

This removes the profile, password hash, selected applications, limits, usage totals, activity rewards, steps, and workout history. It also clears native Accessibility blocking rules and temporary unlocks.

## Outside the application

Google Play requires a public deletion page when an app allows account creation. Host this document at a stable HTTPS URL, add the final support contact, and enter that URL in Play Console. Because no LockFit server exists, the external page should explain that uninstalling LockFit or clearing its Android app storage deletes the only copy; it must not pretend to submit a server deletion request.
